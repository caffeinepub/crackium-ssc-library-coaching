# Specification

## Summary
**Goal:** Replace the existing CRACKIUM SSC coaching website with a completely new website that has a distinct design concept, color palette, typography, and layout — sharing nothing visually with the previous site.

**Planned changes:**
- Remove all existing frontend components, sections, and styles from the CRACKIUM SSC coaching site (orange glow borders, glassmorphism cards, dark theme, SSC content)
- Build a brand-new website with a bold, creative visual theme using a unique color palette (not orange, not blue/purple), intentional typography pairing, and consistent layout
- Apply the new design language consistently across all sections (hero, features, etc.)
- Keep the backend as a minimal empty Motoko actor with no changes

**User-visible outcome:** Users see a completely new, polished website with a fresh visual identity — distinct colors, typography, and layout — replacing the old CRACKIUM SSC coaching site entirely.
